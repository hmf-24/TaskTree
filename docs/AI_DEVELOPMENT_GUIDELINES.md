# AI 开发协作规范 (AI Development Guidelines)

> **重要提示**：这份文档用于记录在使用 AI 编程助手（如 Claude, Gemini, Cursor 等）开发本项目时，必须严格遵守的核心规则。

## 1. 数据库安全与持久化 (CRITICAL: Database Preservation)

**绝对禁止轻易重置或删除本地/生产数据库内容！**

在使用脚本启动环境或执行测试时，如果由于配置变更（如迁移到多应用架构、调整环境变量、切换运行方式）导致似乎"读取不到数据"，AI **必须**：
1. 优先检查数据库文件路径是否偏移（如 `data/tasktree.db` vs `backend/data/tasktree.db`）。
2. 优先检查环境变量加载情况。
3. **不得**擅自清空 `users` 等核心表，也**不得**建议用户"直接使用空数据库重新注册"（除非用户明确同意接受数据丢失）。
4. 保留原本沉淀的用户数据、项目数据和任务数据，它们对用户非常重要。

## 2. 渐进式重构 (Progressive Refactoring)

在执行重构（如将单体拆分为 Workspace 架构）时：
1. 尽量复用已有的代码（例如不要轻易拆分 `Settings.tsx`）。
2. 不要破坏现有的模块功能（特别是钉钉的 AI 机器人等长链路功能）。
