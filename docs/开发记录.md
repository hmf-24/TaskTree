# Nexus 开发记录 (Changelog)

> [!IMPORTANT]
> **Nexus 生态系统演进说明**
> 本文档记录了系统的历史更新轨迹。
> **请注意：** 在早期日志中，系统统称为 "TaskTree"。随着 2026 年 ReadHub 模块的引入与架构升级，系统整体架构现已正式定名为 **Nexus 多模块智能生态系统**，而 "TaskTree" 降级为专指其中的**任务管理子模块**。为了尊重历史，早期的日志内容中仍保留了原有的 "TaskTree" 称呼。

## 版本更新记录

### 2026-05-21: ReadHub 智能标签分级与过滤深度优化 ✅

#### 新增功能与优化
1. **智能分级与标签提取重构**
   - 数据库 `rss_articles` 表结构升级，新增 `importance` (重要度) 和 `tags` (标签) 字段，将 AI 的分析结果进行持久化保存，避免重复运算消耗大模型 Token。
   - `readhub_settings` 表新增 `interest_tags` (用户关注标签)，支持用户个性化设置技术关注点。
   
2. **AI 分析引擎深度强化**
   - 在 `llm_service.py` 的 `batch_analyze_articles` 方法中，强化了 Prompt，明确了“信息技术与信息行业政策”的核心领域。
   - 实现了对无关水文（如社会新闻、生活八卦、消费权益等）的【零容忍】判定规则，强行打上 `unrelated`。
   - 改进了针对“早报/晚报”等聚合类资讯的提取策略，不再机械截断，而是提炼最重要 1-3 条核心信息。
   - 优化了摘要生成的长度限制（40-100字），确保信息增量足够。

3. **前端过滤折叠与设置闭环**
   - **自定义设置**：在 `/app/readhub/settings` 页面增加了可交互的关注标签配置（支持动态添加/删除）。
   - **智能分区展示**：主屏文章列表根据重要度排序展示。`high`（核心必读）、`medium`（推荐阅读）、`low`（边缘资讯）带有不同徽章展示；`unrelated` 的文章强行折叠在最底部，保持页面清爽（Anti-Slop）。

4. **钉钉日报推送（/read）体验升级**
   - **今日概览**：调用 AI 基于前 5 篇最高优先级内容自动生成 80 字以内“🌟 今日核心概览”段落放在推送最前。
   - **全量优质推送**：取消了硬编码的展示条数限制（原 20 条），支持一次性推送百条以内所有未读优质文章。
   - **物理剔除**：钉钉日报中物理剔除了所有 `unrelated` 文章，保证绝无信息干扰。
   - **阅后即焚**：在执行 `/read` 命令时，自动将抓取到的文章标记为已读，确保下一次呼叫时只推送增量全新内容。
   - **格式规整**：每条文章展示携带了重要度 Icon 以及带有 `#` 格式的微型标签，排版更美观。

### 2026-05-12: 统一设置中心架构升级与 Taste Skill 亮色美学重构 ✅

#### 新增功能与重构
1. **统一设置中心架构 (Global Settings Architecture)**
   - 剥离 Nexus 和 ReadHub 专属设置，将系统级（LLM 配置、DingTalk 机器人等）提权为 Nexus 全局设置中心
   - `Settings.tsx` 重构为统一入口，不再耦合特定业务线状态，提高代码扩展性和单向数据流清晰度

2. **Taste Skill (Anti-Slop) 亮色美学全面升级**
   - **基础主题反转**：从深色极客风（Dark Mode）全面重构为类似顶级工具（Linear, Taste Skill 官网）的高反差亮色模式（`theme.defaultAlgorithm`）
   - **深空有机器质感（Organic Blur Background）**：将背景壁纸之上覆盖了强力高斯模糊（`blur: 40px`）和柔和的奶白遮罩（`rgba(253, 252, 251, 0.85)`），把原本抢眼的风景图转化为极其高级且有机的石材底纹/光斑背景
   - **优雅的混合排版（Mixed Typography）**：全局使用 `Inter` 和 `Outfit` 无衬线字体，并特地在核心标题（如 `Projects built with Nexus.`）中点缀优雅的 `Newsreader` 衬线斜体，提升现代感与文字张力。中文字体后备补充了 `PingFang SC` 与 `Microsoft YaHei`，确保多端阅读舒适
   - **卡片微交互（Liquid Hover）**：工作台卡片实现了极简的半透明玻璃态底板（无显性光效），辅以极其细腻的位移（`translateY`）和散开的高质感阴影（`0 16px 40px rgba(0,0,0,0.08)`），达到高级设计的质感要求

### 2026-05-12: ReadHub 自动化闭环与知识沉淀 (阶段三) ✅

#### 新增功能
1. **ReadHub 专属设置系统**
   - 数据库新增 `readhub_settings` 表用于存储每个用户的独立配置（Obsidian Vault 路径、自动拉取间隔等）
   - 前端新增 ReadHub 设置页面（`/app/readhub/settings`），允许用户直接在 UI 配置 Obsidian 知识库集成

2. **Obsidian 知识沉淀服务**
   - 实现 `obsidian_service.py`：支持将 RSS 订阅文章（HTML）自动转化为 Markdown 格式
   - 自动在 Markdown 头部生成 YAML Frontmatter（包含 title, source, author, date, tags 等元数据）
   - 一键将文章安全写入本地 Obsidian Vault 指定目录中

3. **文章转任务链路打通**
   - ReadHub 前端文章详情页新增**"转为任务"**按钮，支持选择目标项目
   - 后端新增 `POST /articles/{id}/convert-to-task` 接口，自动带上文章来源链接与摘要并存入 TaskTree

4. **钉钉 AI 机器人扩展 (ReadHub 专属命令)**
   - `/read` (或 `/阅读`、`/订阅`): 在钉钉中获取今日未读文章摘要及链接
   - `/save <ID>` (或 `/保存`): 在钉钉中通过命令直接将指定文章推送到本地 Obsidian
   - `/convert <ID> [项目名]` (或 `/转任务`): 在钉钉中通过命令直接将文章转化为工作任务
   - 更新系统 `/help` 菜单，按 Nexus 与 ReadHub 分组展示可用指令
